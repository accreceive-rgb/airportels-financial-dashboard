# MAKESEND Financial — MADGA Project

> **MADGA** (Make Department Great Again) — Central source of truth for everything our department does: processes, workflows, tools, stakeholders, and improvement plans.

## How to view the dashboard

1. Open the `dashboard/` folder
2. Double-click `index.html`
3. It opens in your browser — no install needed

## How to update this project

This project is maintained through **Claude**. To make changes:

1. Open this project folder in Claude Code (or share the CLAUDE.md with Claude)
2. Tell Claude what you want to update — e.g., "add a new process called X" or "update the steps for Y"
3. Claude will update the docs and dashboard automatically

## What's inside

| Folder | What it contains |
|---|---|
| `department/` | Team overview, mission, and master process map |
| `processes/` | One folder per process — overview, steps, and detail |
| `plans/` | Improvement plans (problem → analysis → action) |
| `dashboard/` | HTML dashboard — open `index.html` to view |
| `changelog.md` | Log of every update session |

## Working with your team

This project is shared with your team. Here's how it stays in sync:

- **When you start a session**, Claude automatically grabs the latest changes from your team
- **When you make changes**, Claude automatically saves and shares them so your team can see
- **If you're offline**, Claude saves everything on your machine. Next time you're online, it syncs automatically
- **If two people edit at the same time**, Claude merges both changes — nothing gets lost

You don't need to do anything — Claude handles all of this in the background. Just tell Claude what you want to change and it takes care of the rest.

### Quick tips
- Always open Claude when you want to make changes (don't edit files directly)
- If you see a message like "synced changes from [name]" — that means a teammate updated something
- Say **"who changed what"** to see recent updates from the team
- Say **"sync"** if you want to manually grab the latest changes
