# Annual Financial Close & Compliance — ปิดงบประจำปี

## Purpose
ดำเนินการปิดงบการเงินประจำปี ตั้งแต่กระทบยอด Audit Request จัดเตรียมเอกสาร จัดประชุมผู้ถือหุ้น และนำส่งงบ/ภาษีต่อหน่วยงานที่เกี่ยวข้องภายในกำหนดเวลาตามกฎหมาย

## Stakeholders

| Name / Role | Involvement | Internal/External |
|---|---|---|
| โอ๋ (Accounting Manager) | ดำเนินการหลักทุกขั้นตอน | Internal |
| คุณโฮ่ (CEO) | อนุมัติงบ, เข้าร่วมประชุมผู้ถือหุ้น | Internal |
| คุณพอร์ช (ที่ปรึกษาบัญชี) | ให้คำปรึกษา / ตรวจสอบงบ | Internal |
| ผู้สอบบัญชี (Auditor) | ออก Audit Request, ตรวจสอบงบ | External |
| กรมพัฒนาธุรกิจการค้า (DBD) | รับงบการเงิน, บอจ.5 | External |
| กรมสรรพากร (RD) | รับ ภงด.50 / ภงด.51 | External |

## Tools & Systems

| Tool | Purpose in this process | Notes |
|---|---|---|
| PEAK | ดึง GL กระทบยอด Audit Request | — |
| ระบบ RD (e-Filing) | ยื่น ภงด.50 / ภงด.51 ออนไลน์ | — |
| DBD e-Filing | นำส่งงบการเงินกรมพัฒนาธุรกิจ | — |
| หนังสือพิมพ์ | ลงประกาศเชิญประชุมผู้ถือหุ้น | ก่อนประชุมไม่น้อยกว่า 7 วัน |

## Timing

Annual — หลังสิ้นรอบบัญชี (31 ธันวาคม)

| กำหนดการ | Deadline |
|---|---|
| ประชุมสามัญผู้ถือหุ้น | ภายใน 120 วัน หลังสิ้นรอบบัญชี |
| ลงหนังสือพิมพ์เชิญประชุม | ก่อนวันประชุมไม่น้อยกว่า 7 วัน |
| นำส่ง บอจ.5 | ภายใน 14 วัน นับจากวันประชุมสามัญ |
| นำส่งงบ → กรมพัฒนาธุรกิจ | ไม่เกิน 1 เดือน นับจากวันประชุมผู้ถือหุ้น |
| ยื่น ภงด.50 | ภายใน 150 วัน นับจากสิ้นรอบบัญชี (31 ธ.ค. + 150 วัน) |
| ยื่น ภงด.51 | ภายในสิงหาคม (ออนไลน์ได้ถึง 8 กันยายน) |

## Inputs
- GL ใน PEAK (ปิดงบรายเดือนครบแล้ว)
- Audit Request จากผู้สอบบัญชี
- งบการเงินที่ผ่านการตรวจสอบแล้ว

## Outputs
- งบการเงินประจำปี (ผ่านการตรวจสอบ)
- บอจ.5 (นำส่ง DBD)
- งบการเงิน → กรมพัฒนาธุรกิจการค้า
- ภงด.50 / ภงด.51 (ยื่น RD)
- รายงานการประชุมสามัญผู้ถือหุ้น

## Cross-Department Links
- Receives from: Monthly Financial Close (งบรายเดือนครบ 12 เดือน)
- Hands off to: คุณโฮ่ / ผู้ถือหุ้น (งบการเงิน), DBD, กรมสรรพากร
