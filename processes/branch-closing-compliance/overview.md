# Branch Closing — Compliance De-registration

## Purpose
ดำเนินการแจ้งยกเลิกและถอนทะเบียนด้านกฎหมายทุกอย่างเมื่อปิดสาขา ครอบคลุมการแจ้งปิดสาขากับกรมพัฒนาธุรกิจการค้า (DBD), แจ้งยกเลิกสถานประกอบการกับกรมสรรพากร และแจ้งยกเลิกการใช้เครื่องบันทึกการเก็บเงิน (ภพ.06)

## Stakeholders

| Name / Role | Involvement | Internal/External |
|---|---|---|
| โอ๋ (Accounting Manager) | ดำเนินการยื่นเอกสารทุกขั้นตอน | Internal |
| คุณโฮ่ (CEO) | ลงนามเอกสารยื่นราชการ | Internal |
| กรมพัฒนาธุรกิจการค้า (DBD) | รับแจ้งปิดสาขา | External |
| กรมสรรพากร (สรรพากรพื้นที่) | รับแจ้งยกเลิกสถานประกอบการ / ยกเลิก ภพ.06 | External |
