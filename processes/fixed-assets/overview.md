# Fixed Assets — บัญชีสินทรัพย์ถาวร

## Purpose
บันทึก ควบคุม และดูแลบัญชีสินทรัพย์ถาวร (Fixed Assets) ของบริษัท ตั้งแต่การซื้อ การคิดค่าเสื่อมราคา จนถึงการตัดจำหน่าย

## Stakeholders

| Name / Role | Involvement | Internal/External |
|---|---|---|
| AP Officer | บันทึกซื้อสินทรัพย์เข้าระบบ | Internal |
| Accounting Manager | วางแผนและควบคุมบัญชีทรัพย์สิน | Internal |

## Tools & Systems

| Tool | Purpose in this process | Notes |
|---|---|---|
| PEAK | บันทึกซื้อสินทรัพย์ / ทะเบียนสินทรัพย์ | TBD — PEAK รองรับ FA หรือใช้ sheet แยก |

## Timing
As-needed — เมื่อซื้อสินทรัพย์ใหม่ / รายเดือน (ค่าเสื่อมราคา)

## Inputs
- ใบเสร็จ / Invoice ซื้อสินทรัพย์
- ข้อมูลสินทรัพย์ (ราคา, อายุการใช้งาน, วิธีคิดค่าเสื่อม)

## Outputs
- รายการสินทรัพย์ในระบบ
- ค่าเสื่อมราคาประจำเดือน (TBD)

## Cross-Department Links
- Receives from: Expense Reimbursement / การจัดซื้อ
- Hands off to: Monthly Financial Close
