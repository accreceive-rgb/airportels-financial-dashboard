Expense Reimbursement Processing

Expense / AP • AP Officer

partial active

Purpose

ตรวจสอบและดำเนินการเบิกค่าใช้จ่ายต่างๆ ของบริษัท ตั้งแต่รับเอกสาร ตรวจสอบ บันทึกบัญชี จนถึงชำระเงิน

As-needed / Monthly

Steps

บันทึกค่าใช้จ่าย / ตั้งหนี้ (AP Invoice)

# Step Actor Tool Output Notes
1รับใบแจ้งหนี้ / ใบวางบิลจาก SuppliersAP Officerเอกสารใบแจ้งหนี้—
2ตรวจเช็ค: ชื่อบริษัท, เลขผู้เสียภาษี, รายละเอียด, เงื่อนไขชำระ, มีหัก ณ ที่จ่ายไหม/เท่าไหร่AP Officerเอกสารเอกสารผ่านการตรวจ—
3บันทึกค่าใช้จ่ายใน PEAK → รายจ่าย → บันทึกค่าใช้จ่ายAP OfficerPEAKEXP (ร่าง)ถ้าเคยบันทึก Supplier นี้แล้ว: ค้นชื่อ → คลิก EXP → ตัวเลือก → คัดลอก
4ใส่รายละเอียด: วันที่ออก, วันที่ครบกำหนด, หมวดหมู่, รายละเอียด, จำนวน, ราคา, VAT7%, หัก ณ ที่จ่ายAP OfficerPEAKEXP ครบถ้วน—
5ถ้ายังไม่ชำระ → คลิก "ยังไม่ชำระตั้งหนี้ไว้ก่อน" → กด "อนุมัติค่าใช้จ่าย"AP OfficerPEAKEXP ตั้งหนี้แล้ว—
6แนบไฟล์ ใบแจ้งหนี้ / ใบเสนอราคา / ใบส่งของ / ใบกำกับภาษี / ใบเสร็จ / สลิปโอนเงิน ใน EXPAP OfficerPEAKEXP มีเอกสารแนบทำทุกครั้งที่บันทึก

การจ่ายชำระหนี้

# Step Actor Tool Output Notes
7ระบุรายละเอียดชำระ: วันที่, บัญชีที่จ่าย, จำนวน, อัตราภาษี, แบบ ภงด., มูลค่าหัก ณ ที่จ่ายAP OfficerPEAKข้อมูลชำระครบบัญชีบริษัท หรือ เงินสดย่อยตามเคส
8กด "อนุมัติค่าใช้จ่าย" → ตรวจสอบ "ข้อมูลการชำระ" (ยอดชำระ + ยอดหัก ณ ที่จ่าย ถูกต้อง?)AP OfficerPEAKEXP อนุมัติแล้ว—
9พิมพ์ EXP + PV + ใบหัก ณ ที่จ่าย (ถ้ามี) → แนบชุดจ่ายAP OfficerPEAKชุดเอกสารจ่าย—

ออกหนังสือรับรองการหัก ณ ที่จ่าย (กรณีมี WHT)

# Step Actor Tool Output Notes
10คลิก "พิมพ์ใบหัก ณ ที่จ่าย" → Save PDFAP OfficerPEAKไฟล์ PDF ใบ WHTแนบชุดจ่าย + นำส่ง Suppliers
11จัดเก็บไฟล์ใบหัก ณ ที่จ่าย ลง Drive ตามบริษัทและเดือนAP OfficerDriveไฟล์ PDF จัดเก็บAI → AI Accounting → AI Taxation → 50ทวิ → เดือน; MS → MAKESEND Accounting → MAKESEND Taxation → 50ทวิ → 50ทวิ2024 → เดือน
